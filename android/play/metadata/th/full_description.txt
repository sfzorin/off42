OFF42 เปิดและแปลงไฟล์สำนักงานบนโทรศัพท์หรือแท็บเล็ตของคุณ ทุกอย่างเกิดขึ้นบนอุปกรณ์: แอปไม่มีการเข้าถึงเครือข่าย และเปิดหรือบันทึกไฟล์ผ่านตัวเลือกไฟล์ของระบบและการแชร์เท่านั้น

• เอกสาร: ดู DOCX, ODT, RTF, Markdown, HTML และข้อความธรรมดา พร้อมจำนวนคำ และบันทึกเป็นรูปแบบใดก็ได้ในกลุ่มนี้
• สเปรดชีต: XLSX, ODS, CSV และ XLS (อ่านอย่างเดียว) ในตารางพร้อมแท็บชีต บันทึกเป็น XLSX, ODS หรือ CSV
• งานนำเสนอ: PPTX และ ODP เป็นโครงร่างข้อความของทุกสไลด์ แปลงระหว่างสองรูปแบบ
• PDF: แสดงหน้าบนอุปกรณ์ พร้อมเมทาดาทา บุ๊กมาร์ก ไฟล์แนบ และช่องฟอร์ม
• ฉลากและรหัส: QR, Data Matrix, Code 128 และ Aztec แผ่นฉลาก A4 จากบรรทัดของคุณ และเครื่องหมายผลิตภัณฑ์และการรับรองมาตรฐาน 97 แบบ (เป็นภาพเท่านั้น: เครื่องหมายไม่ได้รับรองสิ่งใด)
• ลายเซ็นและตราประทับ: ลายเซ็นแบบลายมือด้วยปากกาและหมึกหลายแบบ และรอยตราประทับจากเทมเพลตในตัว บันทึกเป็น PNG โปร่งใส

ยังไม่รองรับ: การแก้ไข การส่งออกเอกสารเป็น PDF รูปภาพและเลย์เอาต์ของสไลด์ การใส่คำอธิบายประกอบ PDF ลายเซ็นที่วาดเป็นรูปภาพ ไม่ใช่ลายเซ็นดิจิทัลที่ใช้ใบรับรอง

OFF42 ฟรีและเป็นโอเพนซอร์ส (สัญญาอนุญาต MIT) ใช้เอนจินเดียวกับแอป OFF42 สำหรับ Mac, Windows และ Linux และเว็บแอป
